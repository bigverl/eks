## [0.1.0] - 2026-09-07

### Added
- Basic infra: VPC, 2 public, 2 private subnets across 2 AZs, single NAT gateway
- EKS cluster with public endpoint access
- EKS Managed Node Group
- `pokefinder` ECR repository to hold deployment images
